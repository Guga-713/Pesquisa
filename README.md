# Pesquisa

Este é o meu projeto em Python desenvolvido para a atividade de pesquisa de satisfação da ETEC. O objetivo do programa é coletar o feedback dos clientes sobre o atendimento prestado pela empresa.

## Como o programa foi construído:
* **Estrutura de Repetição:** Utilizei o comando `for` para fazer o programa repetir as perguntas automaticamente para cada entrevistado.
* **Coleta de Dados:** O programa solicita que o usuário digite o seu nome, a sua idade e a sua nota/opinião sobre o atendimento.
* **Opções de Voto:** As notas aceitas são 1 para EXCELENTE, 2 para BOM e 3 para RUIM.
* **Estrutura de Decisão:** Usei os comandos `if` e `elif` para verificar qual nota foi digitada e fazer a contagem correta.

## Resultado Final:
Depois que todos os entrevistados respondem, o programa sai do laço de repetição e exibe na tela o relatório final contendo:
* A quantidade total de respostas "EXCELENTE"
* A quantidade total de respostas "RUIM"

O código foi testado com 10 entrevistados para validar o funcionamento e confirmar que a lógica das variáveis contadoras está funcionando perfeitamente.
